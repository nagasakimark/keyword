# Keyword Game

Pick a topic, and the words/pictures are spread evenly across the screen as large as possible.
Click one to make it the **keyword** (it glows, gets a "KEYWORD" ribbon and is shown in the banner at the top), then play any game with it.

**Controls**
- Click a tile to pick the keyword; click it again (or the ✕ / `Esc`) to clear.
- **Pic + Word / Words / Pictures** (`1` `2` `3`): what each tile shows.
- **Shuffle** (`S`) mixes the order; **Pick one** (`R`) spins and lands on a random keyword.
- `M` mute, `F` fullscreen, `Esc` back to the topics.

Plain HTML/CSS/JS, no build step. Open `index.html` via any web server (e.g. `python3 -m http.server`) or GitHub Pages.
Pictures come from the Pokémon Soccer game (downsized for fast loading).
