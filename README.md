# Keyword Game

Pick a topic, and the words/pictures are spread evenly across the screen as large as possible.
Click words to make them **keywords** — pick one or as many as you like. Each keyword glows, gets a "KEYWORD" ribbon and is shown in the banner at the top; then play any game with them.

**Controls**
- Click a tile to add it as a keyword; click it again (or its chip in the banner) to take it off. `Backspace` removes the last one, the ✕ / `Esc` clears them all.
- **Pic + Word / Words / Pictures** (`1` `2` `3`): what each tile shows.
- **Shuffle** (`S`) mixes the order; **Pick one** (`R`) spins and adds a random keyword (press again to add another).
- `M` mute, `F` fullscreen, `Esc` back to the topics.

Plain HTML/CSS/JS, no build step. Open `index.html` via any web server (e.g. `python3 -m http.server`) or GitHub Pages.
Pictures come from the Pokémon Soccer game (downsized for fast loading).
